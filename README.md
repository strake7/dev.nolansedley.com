https://dev.nolansedley.com

A public development journal for notes, ideas, and lessons on building software and leading engineering teams.

Built with [Astro](https://astro.build/)

```sh
corepack enable
pnpm install
pnpm dev
```

Available at `http://localhost:4321`.

## Writing

Posts live in `content/posts` as Markdown or MDX. Each post needs at least a title and date:

Keep images beside their post and reference them with a relative path. A directory named `index.mdx` publishes at the directory path; other files use their full content path.
